About MaizeIQ Kenya

Model is combining machine learning, weather data, and market intelligence to empower Kenyan farmers and traders with price forecasting tools.

The Problem

Smallholder farmers in Kenya often sell maize immediately after harvest when prices are lowest, lacking the information to time their sales. Traders face uncertainty buying in surplus regions to sell in deficit areas. Price volatility causes food insecurity and financial loss across the value chain.

MaizeIQ addresses this by providing data-driven price forecasts that help both farmers and traders make better decisions about when and where to buy or sell.

The Solution

I trained a Gradient Boosting machine learning model on 3 years of wholesale maize prices from 45 Kenyan counties, combined with daily weather data (temperature, rainfall). The model achieves an R² of 0.81 — meaning it explains 81% of price variation with an average error under 1 KSh/kg.

Data Sources

Built on publicly available Kenyan agricultural and meteorological data

🏛

Maize Price Data

Historical wholesale and retail prices from markets across 45 Kenyan counties — 2023 to 2026. Sourced from Kenya market monitoring systems.

🌦

Weather Data

Daily temperature and rainfall data from Open-Meteo — a free, open-source weather API with historical records going back decades.

🗓

Seasonal Features

Kenya's agricultural calendar — long rains (Mar–May), short rains (Oct–Dec) — encoded as features to capture seasonal price patterns.

Technology Stack

Built with open-source tools, deployable on a basic server

🐍

Python + scikit-learn

Gradient Boosting Regressor for price prediction. XGBoost compatible. Trained with cross-validation and feature importance analysis.

⚗

Flask

Lightweight Python web framework serving the REST API and HTML pages. Easy to deploy on any Linux server or cloud platform.

🗄

SQLite

Embedded database storing user accounts, roles, and prediction history. No separate database server required.

🎨

HTML / CSS / JS

Vanilla frontend with no heavy frameworks. Chart.js for data visualisation. Fast, accessible, and mobile-friendly.
